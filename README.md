# Trans — Gift edition (Polished Spanish ↔ English translator)

Hello Jonuco!

This repository contains a single-file, polished translator designed to be shared as a small gift. It uses public LibreTranslate endpoints to translate between Spanish and English in real-time.

Qué hay de nuevo / What's new
- Improved UI with modern typography, gradients and subtle animations
- Swap button, copy/clear controls, and informative status messages
- Small demo text pre-filled so the recipient sees it working immediately

Instrucciones / Instructions

English
1. Enable GitHub Pages for this repository (Settings → Pages → Branch: `main`, Folder: `/`).
2. After a few minutes your live site will be available at: `https://charlieshrooms1.github.io/Trans/`.
3. Send that URL to your friend — they can open it in any browser and start translating.

Español
1. Activa GitHub Pages en este repositorio (Settings → Pages → Branch: `main`, Folder: `/`).
2. Después de unos minutos tu sitio estará disponible en: `https://charlieshrooms1.github.io/Trans/`.
3. Envía ese enlace a tu amigo — puede abrirlo en cualquier navegador y empezar a traducir.

Alternativa rápida / Quick alternative
- Use Netlify Drop: https://app.netlify.com/drop — drag & drop `index.html` to get an instant public URL.

Privacy & reliability / Privacidad y fiabilidad
- Text is sent to third-party LibreTranslate servers. Avoid pasting sensitive content.
- Public endpoints can be rate-limited or offline. If you need a private/stable solution, run your own LibreTranslate server and update the `apiCandidates` list in `index.html`.
