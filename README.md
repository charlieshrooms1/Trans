# Trans — Gift edition (Polished Spanish ↔ English translator)

This repository contains a single-file, polished translator designed to be shared as a small gift. It uses public LibreTranslate endpoints to translate between Spanish and English in real-time.

What's new in the Gift edition
- Improved UI with modern typography, gradients and subtle animations
- Swap button, copy/clear controls, and informative status messages
- Small demo text pre-filled so the recipient sees it working immediately

How to use
1. Save `index.html` and open it in any modern browser (double-click the file) — no server required.
2. Or host it as a static site (GitHub Pages, Netlify, Vercel) to get a shareable link.

Share instructions (quick)
- GitHub Pages: push the files to the repository and enable Pages from Settings → Pages (branch: `main`, folder `/`). The site will be available at `https://charlieshrooms1.github.io/Trans/`.
- Netlify: go to https://app.netlify.com/drop and drop the `index.html` file — Netlify gives you a public URL instantly.
- Email/Zip: Put `index.html` in a zip and send it — the recipient can open it locally.

Privacy & reliability
- Text is sent to third-party LibreTranslate servers. Avoid pasting sensitive content.
- Public endpoints can be rate-limited or offline. If you need a private/stable solution, run your own LibreTranslate server and update the `apiCandidates` list in `index.html`.
